# 上个钩 UI 与 macOS 支持交接说明

本次提交以 GitHub `main` 的 `4e84150`（speaker-aware 漫画对白）为基线。远程提交在本地工作期间产生，因此交付时先保留并集成该提交，再叠加本轮改动；没有回退开发伙伴的漫画生成逻辑。

## 与上一版本的主要差异

### 1. 产品品牌与界面

- 面向用户的产品名统一为“上个钩”，副标题为“为好故事找到吸引力”。
- 建立与知乎生态协调的蓝色、中性色和状态色变量，统一页面背景、文字层级、边框、按钮、输入框、步骤、弹窗和结果区。
- 刘看山作为品牌角色和创作搭档，分别承担导入、理解故事、整理分镜、绘制、配乐、成功、失败和导出反馈。
- 动效使用本地 Three.js 程序化模型，不请求外部资源；具有静态 PNG 回退并支持 `prefers-reduced-motion`。
- 修复 768、390、320 像素下海报编辑器横向溢出、画布裁切、按钮出屏、弹窗滚动和背景列表密度问题。

### 2. 文案与状态表达

- 模型名、内部耗时指标和技术状态不再进入主要创作界面。
- 删除伪百分比和无依据的固定耗时预估；等待页显示真实阶段，不重复堆叠状态。
- “BGM”在主要界面统一为“配乐”；确认弹窗的“情节节拍”改为“文案摘要”。
- 调整错误、成功、授权样例和生成前确认文案，使其更接近创作者语言。

### 3. macOS、API 与 BGM

- 新增 macOS API 配置、启动、停止入口及 npm scripts。
- API Key 写入用户私有配置目录并设置 `600` 权限，不写入仓库。
- 启动器可管理 Stable Audio 3，允许 `--no-bgm`；首次安装会检查磁盘空间。
- 针对默认网络被 VPN 证书代理拦截、而 `en0` 可安全直连的情况，新增仅监听 `127.0.0.1` 的 HTTPS 转发；仍校验证书，不关闭 TLS 校验。

## 已执行验证

- 项目自测：50 项通过。
- 页面布局：15 个场景 × 1440/768/390/320 四种视口，共 60 次自动检查，另人工检查关键截图。
- 390 像素实际操作：导入、分析、海报编辑保存、单图结果和漫画结果可达。
- 正式 API：同一授权样例完成内容分析、单图故事卡、两页漫画和两次 20 秒配乐；图片下载、浏览器音频播放及正式 ZIP 下载通过。
- 正式 ZIP 含最终 PNG、`audio/bgm.wav`、传播文案、发布说明和 manifest，压缩包完整性检查通过。

正式 API 全链路是在集成 `4e84150` 前的 `0501993` 基线上完成；`4e84150` 改变漫画文字嵌入与说话人处理。集成后 50 项项目自测通过，并重新完成 15 场景 × 4 视口的 60 次页面检查；开发侧仍应使用真实作品复核该远程提交的生成质量。

## 开发注意事项

1. 正式页面会加载 `studio-theme.css`、`studio-ui.js`、`assets/design-preview/kanshan-motion.js` 和 Three.js 本地文件，部署时不能漏传资源目录。
2. `design-system-preview.html` 是已批准规范的可交互基准；正式 CSS 以相同 token 落地，但预览页不参与业务流程。
3. 不要将 `~/Library/Application Support/StoryPromoStudio/config.env`、`.runtime/`、日志、模型权重或测试输出加入 Git。
4. 刘看山对外使用的品牌授权由项目方确认；仓库内记录不构成授权证明。
5. 授权样例可能没有真实知乎链接；生成可以完成，但正式发布包要求填写对应原作链接。
6. 若绕过页面顺序，在最终叠字 PNG 尚未上传时直接请求发布包地址，当前异步异常可能导致 Node 进程退出。正常页面会先准备全部图片再显示下载链接，但服务端仍应补防御性异常处理。
7. 本次没有修改远程 `4e84150` 引入的漫画 Prompt。实测旧基线仍出现文字框压到头部的情况；最新的模型内嵌文字方案需要开发结合真实输出继续检查文字准确性、说话人指向和人脸无遮挡。
8. 已验证 macOS；Windows 本轮没有实机复测。既有 Fabric `CanvasTextBaseline` 警告仍存在，但编辑保存流程可完成。
