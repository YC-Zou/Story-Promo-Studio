## 实测发现

1. 漫画第 1 页顶部对白框与人物头部区域重叠。生成图本身可用，问题出现在浏览器后期文字框布局。根据本轮边界，只记录，不修改核心排版。
2. 直接请求发布包地址、但尚未上传所有最终叠字 PNG 时，`streamPublishPackage` 的异步异常没有被外层请求处理捕获，会导致 Node 服务退出。正常页面顺序会先上传图片，因此本次正式页面导出最终成功；该接口仍需要开发侧补充防御性处理。
3. 授权样例的原作链接为空时，生成可以完成，但正式发布包会被阻止。此次为验证导出使用了符合校验格式的测试链接；正式发布前仍应填写对应作品的真实知乎原作链接。

## 结论

在当前 Mac 和当前网络条件下，正式文字 API、图片 API、本地 BGM、浏览器结果呈现、图片下载及 ZIP 导出均实际跑通。该结论不等同于 Windows 实机验收，也不代表漫画文字遮挡已经解决。
