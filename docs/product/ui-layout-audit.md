# 页面排版与文案实测记录

本轮仅调整 UI、响应式样式和展示文案，不修改漫画 Prompt、漫画文字排版、生成请求或核心业务逻辑。测试基于当前工作区；基线为 0501993，保留伙伴的已有修改。

## 覆盖范围与证据

使用独立 4373 测试模式实例，通过浏览器操作同一授权样例：输入、校验错误、服务说明、故事分析、候选文案、形式选择、背景选择、海报编辑、单图生成确认、单图结果、导出就绪、漫画风格、漫画生成确认、漫画结果、问题反馈弹窗，共 15 个场景。

每个场景检查 1440、768、390、320 像素视口，共 60 次检查；最终未检出页面横向溢出、被检查控件越界或隐藏裁切，未捕获页面 JavaScript 错误。另人工查看关键截图，修正了自动检查未覆盖的海报画布缩放裁切。自动结果不代表所有像素和所有内容长度均无问题。

实际下载单图 PNG 成功；ZIP 导出入口进入可下载状态，未解压验收。另以 390 像素视口从输入操作到编辑保存、单图结果和漫画结果。分析接口响应人为延迟以检查真实等待页面，不将延迟视为性能测量。

测试脚本与截图位于 `/tmp/story-promo-playwright/`：`full-layout-audit.mjs`、`mobile-full-flow.mjs`、`audit-*.png`；临时目录可能被系统清理。项目自测 50 项通过，语法检查及差异空白检查通过。

## 已修复

- 编辑器原有桌面最小宽度导致平板、手机横向溢出和操作按钮出屏：改为窄屏预览在前、设置在后的布局。
- 编辑画布按视口缩放并显式设置容器尺寸，避免移动端裁切；仅改变展示，不改变导出尺寸。
- 窄屏背景选项改为双列，改善浏览密度；页头为没有角色的页面释放多余留白。
- 编辑器标题、字数提示、工具栏及页脚对齐和换行优化；弹窗支持视口内滚动，反馈输入框宽度约束完善。
- 提示消息不再拦截指针操作，只展示最新一条，避免堆叠遮挡。
- 确认弹窗不再把每行传播文案误标为“第几页”；“情节节拍”改为“文案摘要”。
- 删除无依据的固定生成耗时区间，改为说明时间取决于服务响应。
- 等待页删除重复状态，并删除移动端无法兑现的顶部步骤返回指引；保留真实状态描述，不新增业务控制。
- 文案校验提示改为“这版文案需要调整”，授权样例提示与创作流程用语统一。

## 边界与遗留

本轮是浏览器真实操作的测试模式 UI 验收，不是新一轮真实模型、真实配乐或 Windows 验收。既有 Fabric CanvasTextBaseline 警告仍存在，编辑保存可完成，未越界修改第三方核心实现。失败、取消等动画的前轮呈现映射测试见实施报告；本轮没有把它们计入上述 15 场景。没有重新承诺漫画遮挡已经解决。

修改文件：`index.html`、`app.js`（展示文案）、`poster-editor.html`、`studio-theme.css`；另更新本记录和实施进度。未修改 API 配置或漫画 Prompt，未推送代码。
