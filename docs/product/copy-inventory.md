## 主页面与等待

| 位置/函数 | 当前文字 | 采用文字或处理 |
|---|---|---|
| 品牌、页标题 | 引力场 | 上个钩；品牌副标题“为好故事找到吸引力” |
| 产品说明 | 知乎故事站外宣发助手 | 知乎故事创作者的宣发工作台 |
| 输入页说明 | 我们只依据正文生成，不补写原作中没有的人物、关系和情节。 | 根据正文准备传播文案和宣传素材。生成内容可能有偏差，请在发布前复核。 |
| 隐私说明 | 本次 Demo…将在 24 小时后删除 | 保留发送正文给已配置 AI 服务的告知；仅从实际运行配置取保存期限，不硬编码、不把真实模式叫 Demo；期限暂不可确认时不显示承诺 |
| 原作链接帮助 | 发布素材需要带回原作入口 | 生成时可暂不填写；下载发布包前需要补充原作链接。 |
| 正文占位 | 在这里粘贴完整短篇正文。超过… | 粘贴完整故事正文；下方固定帮助“最多 50,000 个非空白字符，超出后请删减，不会自动截断。” |
| 文件类型 | 支持 TXT、Markdown、DOCX | 保留，扩展名是用户需要的信息 |
| analyzeBtn | 生成传播文案 | 理解故事并生成文案 |
| 分析初始提示 | 正在建立人物、事件与证据索引… | 正在理解故事并准备传播文案 |
| updateAnalysisProgress | 正在阅读/梳理/准备…＋8%～94% | 删除计时阶段和虚构比例，保留合并等待 |
| 分析成功 | 已准备 N 个传播角度 | 已生成 N 版传播文案，请选择并复核。N 取实际结果 |
| 内容确认忙碌 | 正在检查事实和剧透风险… | 正在检查文案与原作是否一致，以及是否提前揭晓结局… |
| 内容确认通过 | 检查通过，可以继续制作宣传素材。 | 检查通过，请继续选择宣传形式。 |
| 内容确认失败 | 这版文案还不能使用 | 文案需要调整；逐句说明并保留编辑内容 |
| 内容检查未知态 | 等待检查 | 确认前将检查文案 |
| 形式选择 | 连续漫画／单图故事卡 | 保留，两者不是新增串行步骤 |
| 配乐勾选 | 同时生成约 20 秒纯音乐配乐 | 保留，但时长依据实际配置；说明“配乐会增加等待时间，失败不影响已完成的图片。” |
| styleHint | 请选择一种画风／已选择：… | 保留 |
| preflightDialog | 生成预案／查看生成预案 | 生成前确认／查看生成设置 |
| 预期等待 | 约 2–6 分钟／约 30–90 秒 | 无可靠统计时改“生成需要一些时间，你可以返回查看已填写的内容。”，前提是返回行为已修复 |
| progressSubtitle 与 userTaskMessage | 你可以离开本页…／请保持页面打开 | 区分服务端任务和本地视频。服务端任务写“可以返回查看内容，任务仍会继续”；本地合成才要求保持页面打开 |
| task.progress | 任务百分比 | 改为真实子任务状态/已完成页数，不把加权分数当准确比例 |
| 完全成功 | 宣传素材已完成，请查看并复核。 | 素材已准备好，请复核后导出。 |
| 配乐失败 | 图片已经完成，配乐没有生成成功… | 图片已完成。配乐生成失败，可单独重试，也可直接使用图片。 |
| 取消中/已取消 | 正在取消…／生成已取消 | 素材取消接口成功后保留；分析仅中止本地等待时写“已停止等待本次结果”，不得声称上游停止计算 |
| retryTaskBtn | 重试失败部分 | 保留；取消状态不得复用不支持的 retry 接口 |

## 错误与恢复

| 类别/函数 | 当前文字/行为 | 采用文字或处理 |
|---|---|---|
| checkHealth | 生成功能可用／文字生成暂不可用 | 不能仅凭 Key 存在或缺失 services 字段断言；未知响应写“暂时无法确认生成服务状态”，具体配置放详情 |
| analyze TypeError | 正文没有提交成功 | 未能获取生成结果，请检查网络后重试。当前页面中的正文仍保留。不能断言服务器没收到 |
| 429 | 当前生成请求较多，请稍后重试。正文仍保留在本页。 | 保留；仅当错误确属请求限流 |
| 鉴权/配置 | 直接展示 error.message | 生成服务暂不可用，请联系配置人员检查。诊断保留 HTTP 类别，不泄露 Key/原文 |
| 结构校验失败 | 与其他失败混杂 | 这次返回的内容未通过检查，请重新生成。 |
| 确认接口网络错误 | 渲染成与原文不一致 | 未能完成文案检查，请重试。不能制造内容违规判断 |
| pollTask catch | 状态读取失败：原始错误 | 暂时无法更新生成状态，正在重新连接。不要把任务标记失败 |
| 项目恢复失败 | 静默返回输入 | 这篇作品暂时无法恢复，可能已过期或服务暂不可用。按原因提供重新读取或返回输入，不笼统断言删除 |
| 输入超长/未授权/必填 | 明确字段错误 | 保留，在对应输入附近显示，不仅依赖顶部提示 |
| 剪贴板未授权 | 浏览器未开放剪贴板权限 | 无法自动复制，请手动选择并复制文案。粘贴失败则提示直接粘贴 |
| backHookDialog | 已生成的图片和配乐会保留在历史版本中… | 原素材会作为旧版保留。修改并确认文案后，需要重新制作对应素材。仅在版本绑定与保留修复通过后使用 |

## 编辑与导出

| 位置/函数 | 当前文字 | 采用文字或处理 |
|---|---|---|
| 编辑器说明 | 把传播文案排成适合阅读的画面 | 保留 |
| 模板说明 | 不是换皮，是不同的阅读节奏 | 选择适合故事节奏的排版。 |
| 模板说明 | 先抓住最狠的一句 | 突出最有吸引力的一句话。 |
| 保存状态 | 有未保存修改／尚未保存 | 保留；只有实际保存成功才显示已保存 |
| 保存 toast | 定稿已保存，请点击返回开始生成 | 排版已保存到当前浏览器，可以返回继续制作。 |
| 存储失败 | 浏览器存储空间不足，暂时无法保存这张定稿 | 保存失败，浏览器存储空间不足。当前画面尚未保存。保留编辑界面 |
| 背景读取失败 | 底图库载入失败 | 背景未能加载，请重试。 |
| 编辑组件缺失 | 单图故事卡编辑组件载入失败 | 编辑器未能加载，请刷新后重试。不要只弹技术 alert |
| bgmPlayBtn 等 | 试听 BGM／聊天视频使用本次 BGM | 试听配乐／聊天视频使用本次配乐 |
| musicPreset | AI 简洁配乐 | 本次配乐；不把内部预设名当结果品质描述 |
| 无配乐视频 | 本次没有可用 BGM，将生成无声视频 | 本次没有可用配乐，将生成无声视频。 |
| 视频标题 | 视频预览 · 图片 + BGM | 视频预览 · 图片与配乐；无配乐按实际调整 |
| buildChatVideo | 正在生成 N% | 正在合成 N%；比例来自实际录制时长，可保留，不挪用于模型等待 |
| 单页 PNG | 准备第 N 页／PNG 已准备… | 准备第 N 页图片／图片已准备好，请点击下载。PNG 格式标识保留 |
| exportPackageBtn | 准备下载 | 准备发布包 |
| 下载包链接 | 下载类文案 | 下载发布包 ZIP；不隐藏格式，也不声称文件已存入本地 |
| exportPackage 成功 | 文件已经准备好。 | 发布包已准备好，请点击下载。 |
| 下载事件 | 已提交浏览器下载 | 已发起下载，请在浏览器下载列表中确认。 |
| 发布前复核 | 发布前请检查人物、情节、文字和原作信息… | 保留，不能因增加检测而删除人工复核提示 |
| 删除对话框 | 删除这篇作品？…本机文件不会受到影响 | 保留破坏范围与取消选项；按真实服务端删除行为验收 |

技术词规则：主界面不显示模型名、内部评分、服务端原始状态码、耗时指标；PNG/WebM/ZIP、字数、画布尺寸属于用户交付判断所需，保留。异常诊断信息与用户恢复建议分离。不得改写作品正文或已确认传播文案来完成 UI 文案统一。
